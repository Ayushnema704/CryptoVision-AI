# **App Name**: CryptoVision AI

## Core Features:

- Real-time Price Prediction: Display real-time price predictions for Bitcoin and Ethereum using a trained LSTM model.
- Confidence Score Display: Show the confidence level of each prediction with an animated progress circle.
- Historical vs. Predicted Chart: Visualize historical price data alongside predicted values using Recharts or Chart.js.
- Interactive 3D Animation: Hero section features a 3D rotating Bitcoin/Ethereum coin animation to represent predictions.
- LSTM Model Explanation: Provide a brief explanation of the LSTM model and how it captures time-series trends in crypto data.
- Get Prediction: Implement the 'Get Prediction' button that activates an LLM tool that may decide to present its analysis with real-time deep learning predictions powered by LSTM, potentially taking current market sentiment data into account to determine if such analysis can increase accuracy

## Style Guidelines:

- Primary color: Deep blue (#1E3A8A) to establish a sense of trust and sophistication, while aligning with the tech/blockchain theme.
- Background color: Dark grey (#121212) to enhance the futuristic and premium aesthetic, while improving readability for light text.
- Accent color: Neon cyan (#00FFFF) to create a glowing, high-tech feel that highlights key information and interactive elements.
- Body and headline font: 'Space Grotesk' (sans-serif) for headlines and short descriptions paired with 'Inter' (sans-serif) for longer text sections
- Use minimalistic, glowing icons related to blockchain and AI.
- Clean, minimal layout with a modern card-based dashboard. Use smooth scroll animations with Framer Motion.
- Implement subtle animations such as floating particles and animated gradient borders.
